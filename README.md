# saramagowork.github.io

Site pessoal (raiz) e páginas de trabalho:

- `/` site principal: vídeos verticais para Instagram, serviços e contato. Página única em `index.html`; reels otimizados para 3G em `assets/videos/` (`reel-NN.mp4` prévia muda de 6 s, `reel-NN.webp` capa, `reel-NN-full.mp4` vídeo completo com som).
- `veed/`, `flim/` e `squarespace/` variações do mesmo site, cada uma com o sistema visual de uma referência do Refero Styles (VEED, Flim, Squarespace) aplicado à marca Saramago Work. Usam os mesmos vídeos de `assets/`.
- `ledplay/` proposta LED PLAY e `ledplay/demo/` demonstração da abertura do site. Gerado por `deploy_pages.py` na pasta da proposta.
